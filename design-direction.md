# Design Direction

## Project Mood
The website should feel like a **game dev journal wrapped in a dungeon/game interface**. The content should stay process-based and reflective, showing how the project was built, where AI helped, where AI failed, and how the creator made decisions. The presentation should feel more playful and game-like than a standard research paper, closer to a promotional game website that also documents the making process.

The site should not feel like it is only advertising the game. It should clearly communicate the larger AI+Design argument: AI can help beginners build playable games, but the creator still needs to guide, test, edit, reject, and preserve authorship.

## Visual Keywords
- Pixel
- Arcade
- Journal
- Dungeon
- Floor descent

These keywords should guide the visual system. The site should feel like a retro dungeon-crawler interface mixed with a process diary. Viewers should move through the project like they are descending through floors, unlocking parts of the research and development process.

## Color Direction
Use a **dark dungeon palette** inspired by the game’s own background colors. The palette should feel connected to the prototype, not like a separate portfolio template.

The main visual direction should include:

- Dark purple / dungeon-like background tones
- Deep shadow colors for panels and page sections
- Muted yellow / aged gold accents for tabs, panels, section labels, buttons, and important interface details
- Supporting neutral tones only when needed for readability

The muted yellow should feel more like torchlight, aged gold, parchment, treasure, or arcade UI rather than bright neon yellow.

## Typography Direction
Use **clean sans-serif typography for readability**, especially for longer research and process sections.

Use **pixel-style typography as an accent**, not as the main reading font. Pixel type can appear in:

- Section labels
- Buttons
- Navigation tabs
- Small UI details
- “Floor 01,” “Quest Log,” “Debug Room,” or similar labels
- Game-like headings or badges

The typography should balance readability with game identity. Avoid using pixel fonts for long paragraphs because the site needs to stay easy to read.

## Layout Direction
Use a **hybrid structure**: part scroll page, part clickable game interface.

The home page should act like a summary screen or game landing page. It should include:

- The project title
- The research question
- A short project summary
- A quick preview of the game or prototype
- A preview of the process / AI-assisted workflow
- Clear navigation into the main sections

The site should not be one extremely long single-scroll page. Instead, use clickable tabs, panels, or page sections that switch or reveal content. Possible main tabs/pages:

- Home / Start
- Research
- Process
- AI Failures / Debugging
- Prototype / Game
- Reflection / Takeaways

The structure can borrow from game menus, quest logs, dungeon maps, or floor selection screens, while still being simple enough for visitors to understand immediately.

## Image / Media Direction
Use screenshots, gameplay clips, prompt screenshots, debugging evidence, and prototype images as the main visual material.

Media should feel like evidence from the development journey, not just decoration. Strong media categories include:

- Beginner learning evidence
- AI planning evidence
- Core prototype evidence
- AI failure / debugging evidence
- Dungeon loop evidence
- Gameplay screenshots or clips

Images and videos can be placed inside dark panels, cards, tabs, or “rooms.” Captions should explain why the evidence matters, especially when showing AI limitations, debugging moments, or creator decisions.

## References
**Game reference:** Soul Knight by ChillyRoom, but darker.  
Use this as inspiration for the playful pixel dungeon feeling, arcade energy, readable UI, and roguelike attitude. The site should not copy Soul Knight directly; it should use the reference as a mood guide.

**Website layout reference:** Terraria’s official website, but adapted to this project’s darker dungeon aesthetic.  
Use this as inspiration for a promotional game-site structure with a strong home page, visual sections, screenshot/media blocks, feature-style sections, and clear navigation.

## Avoid
Avoid colors and combinations that clash with the purple and muted yellow palette or create poor readability.

Avoid:

- High-saturation red that clashes with purple
- Dark blue placed on purple when it becomes muddy or hard to see
- Yellow on green combinations with poor contrast
- Random neon colors that make the palette feel unintentional
- Low-contrast text, panels, buttons, or tabs
- Pixel fonts for long body text
- A design that feels only like a game promo site and loses the research/process argument
- A single long page that forces every section into one continuous scroll

## Notes for the Coding Agent
Build the site as a **playful, dark, retro dungeon-style project website** with a game dev journal structure.

The design should combine:

- A dark purple dungeon background system
- Muted yellow / aged gold UI accents
- Clean readable sans-serif body type
- Pixel-style accent type for labels and UI moments
- Clickable tabs or panels for navigation
- A home page that summarizes the project and previews the game/process
- Separate sections or pages for research, process, debugging/failures, prototype, and reflection

The site should feel:

- Balanced between minimal and chaotic
- Slightly academic, but still playful
- Slightly gritty
- More handmade than polished
- Mostly retro rather than futuristic
- Mostly dark rather than bright

Do not make final visual choices that ignore the approved direction. Keep the project’s authorship and process visible. The website should show that the creator used AI as a technical assistant, not as a replacement for creative decision-making.
